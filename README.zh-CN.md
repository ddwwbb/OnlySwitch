## OnlySwitch 是什么？
OnlySwitch 提供一系列开关，简化你的日常操作，例如隐藏桌面图标、深色模式、隐藏新 MacBook Pro 的刘海。这些开关显示在状态栏上，你可以轻松控制。开关和快捷指令项可以自定义（移除/添加或排序）以显示在列表中。这些功能甚至可以作为小组件放置在桌面上。

从 1.7 版本开始，**快捷指令（Shortcuts）**可以导入到 OnlySwitch。

从 2.0 版本开始，支持**键盘快捷键**。你可以用键盘控制所有开关和快捷指令。

从 2.3.6 版本开始，开关的可用性入口（包括播放器和隐藏菜单栏图标）已移至系统的菜单栏。

![](https://github.com/jacklandrin/OnlySwitch/assets/3782279/11c89e33-2007-4913-b320-47c188538b68)

从 2.5.0 版本开始，OnlySwitch 开始支持 **Apple 小组件**（Sonoma 及以上）。

从 2.5.4 版本开始，OnlySwitch 提供 Only Control 外观。

从 2.7.0 版本开始，OnlySwitch 包含一个可选的**桌面宠物**：一个始终置顶的小桌面伙伴。在通用设置中启用它，把它拖到屏幕任意位置，点击它即可显示或关闭 Only Control。

### OpenClaw（自然语言）

你也可以使用 [OpenClaw](https://openclaw.ai/) 通过**自然语言**控制 OnlySwitch。本仓库内置了一个 OpenClaw 兼容的 skill：说类似*"清空废纸篓"*、*"切换保持唤醒"*、*"打开深色模式"*的话，OpenClaw 会通过 deeplink 触发对应的开关。设置方式见 [OpenClaw/README.md](OpenClaw/README.md)（额外的 skill 目录，或复制到 `~/.openclaw/skills`）。

## Only Widget

从 2.5.0 版本开始，OnlySwitch 支持 Apple 小组件。小组件可以编辑为任意内置开关和按钮。点击它们会触发对应开关和按钮的响应。你可以把 Only Widget 放在任意位置：桌面或通知中心。

**注意：** 更新到 2.5.0 后，你可能需要重置语言。如果你的小组件没有跟随你的语言设置，请结束 Only Widget 进程，它会自动更新。

## AirPods 开关
我用 `classOfDevice`（2360344）来判断蓝牙设备是否为 AirPods Pro，但我不确定其他 AirPods 型号是否也是 2360344，因为我只有两款 AirPods Pro。如果你使用的是 AirPods 1~3，请告诉我 `classOfDevice` 是多少。或者我可以通过检测电池值的数量来判断是否为 AirPods（数量为 3 时即 AirPods），类似 **AirPods Battery Monitor For MAC OS**。

## 隐藏新 MacBook 刘海

隐藏刘海开关仅显示在 M1 Pro/Max MacBook Pro 的内置显示器上。该开关只控制当前桌面，不是所有工作区桌面。
现在，隐藏刘海开关支持动态壁纸，只是处理需要更长的时间。

## 低电量模式
低电量模式使用的终端命令需要 root 权限，因此每次切换时 App 都会要求你输入密码。

## 屏幕检测与清洁
在 2.3 版本中，OnlySwitch 带来了一个新功能：屏幕检测。它提供全屏的纯色画面，你可以用它检查坏点。按左右方向键，颜色会在黑、白、红、绿、蓝之间切换。这个功能也可以用于屏幕清洁，因为你可以看清屏幕上的污渍。

## 隐藏菜单栏图标
这个功能于 2.3.2 版本新增。说实话，Hidden 和 Dozer 都是这个功能很不错的 App。很多用户同时安装 OnlySwitch 和它们，但这也会挤压本来就不充裕的菜单栏空间。因此这个功能被集成到了 OnlySwitch。
![](https://github.com/jacklandrin/OnlySwitch/assets/3782279/fdda284e-929f-400e-aba5-9c628f065de6)
当开关开启时，分隔图标（箭头所指）左侧的项目会被隐藏。按住 ⌘（Command）并拖动该图标可以配置隐藏区域。如果你不再使用它，可以在偏好设置中禁用，分隔图标会消失。你也可以在这里设置自动隐藏的时间间隔。如果开启后菜单栏上的日期被截断，可以这样设置：系统偏好设置 → Dock 与菜单栏 → 时钟 → 显示日期 → 始终。

从 2.3.10 版本开始，这个开关可以通过右键点击图标来控制。
